Privacy policy

Last updated: 11 October 2026

This policy applies to Reminders Email, a personal macOS tool that emails the user's Apple Reminders items through the user's own Gmail account.

Data the app accesses

  • Apple Reminders: the title, notes, list name, due date and priority of incomplete reminders, read from the user's own Mac.
  • Google account: permission to send email as the user through Gmail's SMTP service. The app does not read, list, search or delete the user's email.

How the data is used

Reminder content is used only to build the email that the user's own configuration asks the app to send, to the recipient addresses the user has configured. Google account access is used only to authenticate and send those emails.

Where data is stored

  • The OAuth refresh token is stored in the macOS Keychain on the user's Mac. Access tokens are short-lived and are not stored.
  • Settings and run logs (reminder titles and outcomes) are stored in files on the user's Mac.
  • The developer operates no server and receives no data. Nothing is transmitted to any party other than Google (to sign in and send mail) and the email recipients the user configured.

Sharing and disclosure

The app does not sell, share or transfer user data to third parties, and does not use it for advertising.

Google API Services User Data Policy

The use and transfer of information received from Google APIs by Reminders Email adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data stays on the user's Mac until the user removes it. Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's Keychain item and its settings and log folders removes everything it stores.

Changes

If this policy changes, the date above will be updated.
