Reminders Email

Reminders Email is a small personal tool for macOS. It reads incomplete items from the Apple Reminders app on the user's own Mac, sends each one as a plain-text email through the user's own Gmail account, and then marks the item complete.

What it does

  • Runs on the user's Mac on a schedule: a frequent run for reminders that start with a keyword such as "send", and a daily digest run.
  • Sends mail only from the user's own Gmail address, using Google's SMTP service.
  • Requests one Google permission, access to send mail as the user (https://mail.google.com/), because Gmail's SMTP service requires that scope for OAuth sign-in.
  • Has no server, no accounts and no analytics. Nothing is sent to the developer.

Who it is for

The app is built and used by its developer for personal use. It is not offered as a hosted service.
